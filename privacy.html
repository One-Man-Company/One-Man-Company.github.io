Privacy Policy

Hermes Workspace Connector — effective 22 October 2026

Hermes Workspace Connector ("the application") is a private, single-user client used by its owner to let a self-hosted Hermes agent work with the owner's own Google Account. This policy explains what Google user data the application accesses, how it is used and stored, and with whom it is shared.

1. Google user data we access

With the owner's explicit consent, the application requests the following Google API scopes:

  • gmail.readonly — read the owner's Gmail messages.
  • gmail.send — send mail from the owner's Gmail address when the owner asks.
  • gmail.modify — apply labels and mark messages read or unread at the owner's request.
  • drive — find, read, create, upload and download files in the owner's Google Drive, including Google Sheets and Google Slides files.
  • spreadsheets — read and update the owner's Google Sheets.
  • documents — read, create and edit the owner's Google Docs.
  • calendar — read and manage events on the owner's calendars.
  • contacts.readonly — read the owner's Google Contacts.

The application accesses only the account that authorizes it, and only the scopes listed above. It does not access any other Google Account.

2. How the data is used

Google user data is used for one purpose only: to carry out tasks that the owner explicitly asks the agent to perform on the owner's own data — for example "find the invoice I received last week", "add a row to this spreadsheet", or "draft a reply to this message". Data is never used to build profiles, never analyzed for advertising, and never used to train machine-learning models.

3. How the data is stored

OAuth credentials (an access token and a refresh token) are stored in a private file on the owner's own computer, readable only by the owner's operating-system account. Any message content, file content or other Google user data the application retrieves is processed locally on that same computer and is retained only as long as the owner's own local history keeps it. The application operates no server, no cloud database, and no hosted service of its own; no Google user data is transmitted to any third party.

4. Sharing and disclosure

We do not sell, rent, trade or otherwise share Google user data with any third party. Data is not disclosed to advertisers, data brokers or analytics providers. Data would be disclosed only if strictly required by law, and only to the extent legally required. The application contains no advertising, no third-party analytics and no tracking.

5. Google API Services User Data Policy and Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide or improve the owner's own user-facing features.
  • Google user data is not transferred to third parties except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition with notice to users.
  • Google user data is not used for advertising, including retargeting or personalized advertising.
  • Google user data is not used to determine creditworthiness or for lending purposes.
  • Humans do not read Google user data unless the owner asks for help with their own data, it is necessary for security purposes, to comply with law, or with the owner's explicit consent.

6. Retention and deletion

Google user data is retained locally only while it remains useful to the owner, and the owner may delete it at any time from their own machine, including by deleting the stored credential file. Access can be revoked at any time at myaccount.google.com/permissions; once access is revoked, the stored credentials stop working immediately and the application can no longer read any Google user data. Requests to delete data can also be raised through the contact link below.

7. Security

Credentials are stored with owner-only file permissions on the owner's computer. All communication with Google APIs takes place over TLS/HTTPS. The owner's computer account is protected by the operating system's own login security.

8. Children

The application is not directed at children, and it has no users other than its owner.

9. Changes to this policy

Any changes to this policy will be published on this page with an updated effective date.

10. Contact

Questions about this policy, or requests concerning Google user data held by the application, can be raised in the site repository: github.com/One-Man-Company/One-Man-Company.github.io/issues.
