One-Man-Company

Fully automating everything with AI.

A company of one, run by agents. The goal is straightforward: hand every repeatable task to autonomous AI — research, writing, coding, monitoring, triage, bookkeeping, the lot — and keep only the judgment for the human. Everything here is built in the open, one project at a time.

Each repository below is one working part of that machine: separate tools that plug into the same agent runtime and run on my own hardware. More get added as the automation reaches further.
